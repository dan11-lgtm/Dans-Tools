Project File

Back up, hand over, or move the audit between machines

The export bundles project metadata, every finding, and all photos into one file. Browser storage is not a backup — clearing site data destroys an unexported audit. Export at the end of every site visit. Import replaces everything on this device; Merge appends another team member's findings (and photos) to this audit and keeps the current project details.

Offline Readiness

What is cached on this device

Alpine, Leaflet and fflate are cached locally on first successful load, so the tool opens with no connection. The HEIC converter (~3 MB) is cached the first time it is used, or now.

Satellite tiles viewed while online are cached automatically. Pre-cache a corridor from the map screen before heading out.
